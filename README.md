# Time-Series-Analysis
End-to-end time series forecasting pipeline: EDA (trend, seasonality, ACF/PACF), baseline vs ETS/ARIMA/SARIMA with justified transforms, time-based train/test evaluation (MAE/RMSE/MASE), residual diagnostics (Ljung-Box), and a reproductible knitted HTML report. Tools: R(forecast, tidyverse) / Python (statsmodels)
